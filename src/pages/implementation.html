The four sessions

From vague idea to working prototype.

Session 1

Problem definition & architecture

Understand the problem and user, define requirements and success criteria, choose models, tools and data sources, design the architecture, and identify security, privacy, cost and failure risks.

Scoped specification, architecture diagram, build plan
Session 2

Build the core functionality

Configure the model or service, build the core together, connect the data source or integration, then run a first test and fix basic issues.

Working initial prototype with one main use case
Session 3

Integrations, reliability & evaluation

Add the next integration, test representative inputs and edge cases, add validation, error handling and human approval where needed, and review latency, costs and privacy.

Tested prototype with documented limitations and operating procedure
Session 4

Finalise, demonstrate & hand over

Complete the agreed scope, test end to end, walk through configuration, usage and maintenance, and review what deployment would need.

Working prototype, usage docs, test results, next-step plan

Questions, answered

Why is the price "from" ₹14,999?

Every project is different. ₹14,999 covers a tightly scoped prototype. Larger scopes, extra integrations or more complex data are quoted after the discovery call, in writing, before you pay anything.

Do I need to know how to code?

Not always. Many workflows use no-code or low-code tools. Developers can go deeper into code. Tell me your level in the application and we'll scope accordingly.

Who owns what we build?

Ownership terms are agreed in writing as part of the scope, before work starts.

Will it be ready for production?

You'll have a working, tested prototype within the agreed scope. Production systems need authentication, monitoring, backups, hosting and maintenance, which can't responsibly be promised inside every four-session package. We'll map out exactly what deployment would need.

Is the Intensive refundable?

Payments are non-refundable once the scope is agreed and paid. If I fail to deliver any of the four sessions, you're refunded for each undelivered session. See the refund policy.

What about API and software costs?

Any third-party costs are paid by you, and only after you approve them.
